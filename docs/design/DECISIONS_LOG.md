# Design decisions and reference traceability

Date: 20 October 2026. Source: five approved page screenshots and two original logos supplied in this task.

| ID | Reference | Observed direction | Delivered decision | Reason / verification |
|---|---|---|---|---|
| D01 | Wide and circular logos | White A, folded purple W, rising arrow; white/purple wordmark | Preserve source pixels; sample actual palette; separate emblem and arrow crops | No invented mark. Original geometry is retained; transparency extraction is documented |
| D02 | Home hero | Copy left, mountain road right, Earth overhead | Same split composition; generated terrain + separate SVG road/signs + authentic emblem | Every motion layer exists independently |
| D03 | Home service section | Six distinct services in a compact 3 × 2 arrangement | Same exact Module 0 taxonomy; 3/2/1 responsive columns | No service collapsed into a generic “digital” card |
| D04 | Home proof strips | Counters, named client logos and testimonials | Remove unsupported proof sections | No real client inputs were supplied |
| D05 | About | Less crowded hero and Mission/Vision/values | Preserve these sections; quiet still artwork and restrained reveals | No new busy feature sections or invented team |
| D06 | Portfolio | Layered cinematic project browsing | Perspective stack, side cards, filters, thumbnail rail, accessible details | Three original concept templates stand in for permission-cleared client media |
| D07 | Blog | Four editorial cards and same-page reader | Query-based reader, TOC, progress, related content and history restoration | Browser interactions verified; sample editorial text has no fake authors/dates |
| D08 | Contact | Purple envelope/planet, form and next steps | Preserve hierarchy; original envelope layer; complete form-state studies | No fake phone, email, address, hours or SLA |
| D09 | All navbar variants | Eight navigation links and strategy-call button | Use exact “Let's Grow”; remove Pricing; Process/Services link to Home anchors | Current user brief and Module 0 take precedence |
| D10 | All pages | Very bright magenta fills and glow | Palette sampled from logo; primary fills darkened, glow limited to selected elements | White button labels exceed 4.5:1 at both gradient ends |
| D11 | All typography | Rounded, heavy headlines | Self-hosted Plus Jakarta Sans, 800 display, 400 body | Original font unavailable; licensed reproducible substitute |
| D12 | All page screenshots | Desktop-only source compositions | Explicit five-width layout rules and separate mobile scene stacking | 25 page/width captures checked for overflow and missing assets |
| D13 | Earth | Rich cinematic sphere | Original beauty still + actual textured 3D asset + low-cost geographic alternate | Still and WebGL are clearly distinguished; real model validates |
| D14 | Motion | Continuous Earth, sequential ascending milestones | 7.2s GSAP reference; 72s Earth spin; 28/42s independent orbital nodes | Eight storyboard beats; reduced motion and replay semantics recorded |
| D15 | Footer CTA | Planet-horizon strip | Reuse Earth artwork inside an editable wide horizon composition | Lightweight reuse, no whole-page screenshot |

Comparison boards in `design-assets/previews/comparisons/` juxtapose source and reconstruction at equal widths. They are for visual inspection, not pixel-diff scoring: sections with unverified facts are intentionally absent, copy changes alter page heights, and the production model is an original interpretation of the reference aesthetic.

No user approval is inferred from these design decisions. This is the concrete review package requested by the brief.
